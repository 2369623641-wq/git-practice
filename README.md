# git-practice

《开源软件开发与技术》（OSSDT-26）作业 2 的个人 Git 练习仓库。

## 用途

- 练习分支创建、切换、提交、推送与 Pull Request 合并。
- 与同学协作，制造并解决一次真实的合并冲突。

## 文件说明

| 文件 | 说明 |
| ---- | ---- |
| `README.md` | 仓库说明（本文件） |
| `practice.md` | 用于修改与合并冲突练习的文本文件 |

## 分支约定

- `main`：默认分支，保存已合并的练习结果。
- `feature/intro`：个人的功能分支。
- `conflict-resolution`：解决冲突后存放提交的分支。
